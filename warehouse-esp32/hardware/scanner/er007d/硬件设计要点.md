# ER007D 手持扫码机 · 硬件设计要点

更新：2026-11-13

## 1. 总体方案

| 项目 | 选型 |
|---|---|
| 主控 | ESP32-S3-WROOM-1U-N16R8（外接 IPEX 天线，需配 2.4G 天线） |
| 扫码模组 | ER007D，12 针 FPC 排线，3.3V 供电，UART 9600-8-N-1 |
| 屏幕 | 240×240 SPI（ST7789，7 针，无 CS） |
| 下载/调试 | ESP32-S3 原生 USB（Type-C 直连 IO19/IO20），**不用 CH340 和自动下载电路** |
| 3.3V 稳压 | TLV75733PDBVR（1A，SOT-23-5，与 AP2112K 引脚兼容） |

**避开**：IO3、IO45、IO46（启动配置脚）。

## 3. 各部分电路要点

### 3.1 USB（Type-C）
- CC1、CC2 各 5.1k 下拉到 GND（已有）
- D+ → IO20，D- → IO19；可选：各串 22Ω，加 ESD（如 USBLC6-2SC6）
- Arduino 中打开 “USB CDC On Boot: Enabled”
- USB 失效时：按住 BOOT，再按复位，进入下载模式

### 3.2 复位 / BOOT
- EN：10k 上拉 + 1µF 对地（**不要用 10µF**）+ SW1 复位键
- IO0：10k 上拉 + SW2 BOOT 键

### 3.3 ER007D 接口（FPC1，12 针 + 2 固定脚）

| FPC 脚 | 定义 | 处理 |
|---|---|---|
| 1 | FLASHDWN | NC |
| 2 | VCC | 接 AO3401A 的 D，旁边加 10µF + 100nF |
| 3 | GND | GND |
| 4 | RXD | ← IO17（串 1k） |
| 5 | TXD | → IO18 |
| 6、7 | D-、D+ | NC（不用 ER 的 USB） |
| 8 | POWERDOWN | NC |
| 9 | BEEP | NC（蜂鸣器由 ESP32 控制） |
| 10 | LED | NC |
| 11 | NC | NC（如卖家说是 WAKE，可留 0Ω 不焊接到空闲 GPIO） |
| 12 | TRIG | ← IO16（串 1k），拉低开始扫码 |
| 13、14 | 固定焊盘 | 接 GND |

- **ER 电源开关**：Q1 用 **AO3401A（P-MOS）**，不能用 AO3400A
  - S → SYS3V3，D → FPC 2 脚，G → ER_EN，G–S 之间接 10k
- **FPC 座**：先量排线间距（0.5 / 1.0mm），确认上接 / 下接，用万用表确认 VCC、GND 的方向后再定封装

### 3.4 屏幕（CN2，7 针）
- 当前顺序：1 BLK、2 DC、3 RES、4 SDA、5 SCL、6 VCC、7 GND
- **对照实物确认**：很多屏幕是 1 脚 GND（顺序相反）
- 无 CS 的 ST7789 屏，软件里 SPI 通常要用 mode 3

### 3.5 电池电压检测
- VBAT —R4 100k— BAT_ADC —R1 100k— GND，BAT_ADC → IO1
- BAT_ADC 对地加 100nF
- 上端必须接电池正极（稳压之前），不能接 SYS3V3 / VBUS
- 程序：`analogReadMilliVolts(1) * 2` = 电池电压

### 3.6 3.3V 稳压
- U21：AP2112K（600mA）不够 → 换 **TLV75733PDBVR**（1A，同封装同引脚）
- 输入电容 10µF，输出电容 10µF + 100nF
- 模组 3V3 脚旁边另放 22µF + 100nF
- EN 目前直接接 VIN → 设备无法关机（见待办）

## 5. 写固件时要记住

- ER 断电前：UART1 TX（IO17）、TRIG（IO16）先设为输入或输出低，防止倒灌
- ER 上电（ER_EN 拉低）后再初始化 UART1
- TRIG 用“开漏”方式：输出低 = 扫码，其余时间设为输入
- ER007D 串口命令（来自卖家命令表，需实测）：
  - `S_CMD_020D` 切换到命令模式
  - `SR030301` 开始扫码
  - `SR030300` 停止扫码
