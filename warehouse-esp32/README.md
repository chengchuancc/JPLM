# ESP32 扫码出入库终端

本目录集中存放 JPLM ESP32 版扫码出入库终端的文档、硬件资料与固件工程。

## 当前状态

- 处于原理图审查阶段，尚未导入或创建可编译的固件工程。
- 主控：ESP32-S3；历史讨论涉及 N16R8，实际模组完整料号待核实。
- 屏幕：用户确认 1.33 寸、240×240 TFT；驱动芯片、接口电气规格及背光驱动待确认，不能仅按尺寸认定为 ST7789。
- 扫码模块：ER006；用户确认兼容，完整手册待补充。
- 输入：5×4 按键矩阵、独立扫码键；输出：屏幕、蜂鸣器。
- 后端：复用 JPLM 的登录、物料查询和出入库 API。

## 目录

- `docs/gpio-review.md`：根据 SVG 原理图核对的 GPIO 表、风险与建议。
- `hardware/`：存放后续提供的 EDA 源工程、原理图 PDF、BOM、PCB 和器件手册。
- `firmware/`：存放后续固件工程；框架和引脚确认前不创建虚假的可运行工程。
