# 出入库登记终端

在 Raspberry Pi OS 的图形桌面中运行。依赖系统的 Python 3、PyGObject、GTK 3 和桌面图标工具。

```sh
sh install.sh --autostart
```

省略 `--autostart` 时可从桌面图标或应用菜单手动打开。

首批名单由 PLM 管理员从 `/JPLM/api/users` 读取，将每项的 `name` 和 `email` 写入 `~/.config/jplm-warehouse/users.json`。管理员登录终端后可以点「同步账号」更新这份名单。操作员点姓名后只输入 PLM 密码。密码与会话 cookie 保留在进程内。

在出入库登记界面，键盘式扫码枪可以在输入框失去焦点时直接扫码。常用 PLM 料号和物料二维码支持无结束键的扫码枪，其他条码请使用带回车或 Tab 结束键的扫码枪。手工输入料号时可用屏幕数字键盘，输入后点「查询」。

支持入库、出库和报废。料号和数量输入界面左侧显示操作，右侧显示大号数字键盘。点顶部「我的出入库记录」可查看最近 30 条个人记录，以及删除有权操作的记录。库存和权限以 PLM 接口为准。
